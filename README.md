# planbook · 旅行行程规划

一个**零依赖、纯静态**的旅行行程规划单页应用。没有构建步骤、没有后端、没有网络请求，用浏览器直接打开 `index.html` 即可使用。

## 功能

- 📅 **多日行程** —— 逐日添加活动（时间 / 地点 / 备注），支持编辑、删除、按时间自动排序；可添加 / 删除一天，修改日期与当天主题。
- 💰 **预算跟踪** —— 设置总预算，按类别（交通 / 住宿 / 餐饮 / 门票 / 购物 / 其他）记账，自动汇总已花费、剩余金额、超支提醒和分类占比。
- 🎒 **打包清单** —— 按分类勾选物品，实时显示打包进度。
- 💾 **本地存储** —— 全部数据保存在浏览器 `localStorage`（键名 `planbook.v1`），刷新、关闭浏览器后仍在。
- 📤 **JSON 导入 / 导出** —— 一键备份为 JSON 文件，或从 JSON 文件恢复，方便换设备迁移。
- 🧪 **内置示例数据** —— 首次打开自动载入「杭州 3 日悠闲游」示例行程（含活动、支出与打包清单），也可在「数据管理」中一键恢复或清空。

## 快速开始

方式一：直接双击 `index.html` 用浏览器打开。

方式二（推荐）：起一个本地静态服务：

```bash
cd planbook
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 数据格式

导出的 JSON 与 `localStorage` 中保存的结构一致：

```json
{
  "version": 1,
  "trip": {
    "title": "杭州 3 日悠闲游",
    "days": [
      {
        "id": "唯一ID",
        "date": "2026-10-24",
        "note": "抵达 · 西湖东线",
        "activities": [
          { "id": "唯一ID", "time": "09:30", "place": "抵达杭州东站", "note": "地铁 1 号线到定安路" }
        ]
      }
    ]
  },
  "budget": {
    "total": 2600,
    "expenses": [
      { "id": "唯一ID", "date": "2026-10-24", "category": "交通", "amount": 480, "note": "高铁往返票" }
    ]
  },
  "packing": [
    { "id": "唯一ID", "text": "身份证", "category": "证件", "packed": true }
  ]
}
```

导入时要求文件包含 `trip.days`、`budget.expenses`、`packing` 三个数组，其余字段会自动补默认值，未知类别归入「其他」。

## 注意事项

- 数据只存在**当前浏览器**里：清除浏览器数据、隐私模式或换设备都会导致数据丢失，重要数据请及时用「导出 JSON」备份。
- 支持现代浏览器（Chrome / Edge / Firefox / Safari 的近期版本），依赖 `localStorage` 与 `<input type="date/time">`。
